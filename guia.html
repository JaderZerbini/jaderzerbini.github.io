Do zero ao GitHub

Seu primeiro portfólio no ar, sem instalar nada e sem saber programar: uma IA gratuita escreve a página, você conta a história e publica tudo pelo site do GitHub. Siga na ordem. Tempo total: de 30 a 45 minutos.

O que você vai precisar

  • Um computador com navegador (Chrome ou Edge) e o Bloco de Notas.
  • Um e-mail, de preferência o da faculdade, para pedir os benefícios de estudante.
  • Um projeto que você fez na faculdade: uma análise, um painel, um modelo, um trabalho de disciplina, o TCC.
O portfólio vai ser público: qualquer pessoa na internet vai poder ver a página e o arquivo dela. Nada de dado pessoal de outras pessoas, dado de empresa ou senha. O passo 3 mostra o que conferir.

Passo 1 · Criar a conta no GitHub

  1. Abra github.com/signup, informe e-mail e senha.
  2. Escolha um nome de usuário profissional, porque ele vira o endereço do seu site: o usuário mariasilva terá o site mariasilva.github.io. Evite apelidos e números aleatórios.
  3. Confirme o e-mail e ative a verificação em duas etapas quando o GitHub pedir (um app autenticador no celular resolve).
  4. No perfil (sua foto → Your profile → Edit profile): coloque foto, nome completo e uma bio de uma linha, por exemplo "Estudante de Ciência de Dados · Python, SQL e visualização".
  5. Opcional: com o e-mail da faculdade, peça o GitHub Student Developer Pack, com ferramentas pagas de graça enquanto você estuda.

Passo 2 · Criar a página com uma IA gratuita

O portfólio é uma página só, um arquivo chamado index.html. Você não precisa escrever o código: a IA escreve, a história é sua.

2.1 · Responda as perguntas sobre o seu projeto

Todo projeto do portfólio é contado em quatro partes. Escreva com as suas palavras:

  • Problema: quem tinha qual dificuldade, e por que isso importa?
  • O que eu fiz: a solução, em uma ou duas frases que qualquer pessoa entenda.
  • Como: os dados, o método e as ferramentas (Python, Pandas, Excel, Power BI...).
  • Resultado: o que você conseguiu. Só números que você tem de verdade.

2.2 · Peça a página à IA

Serve qualquer uma na versão gratuita: ChatGPT, Gemini, Microsoft Copilot ou Claude. Copie o pedido abaixo, troque tudo o que está entre colchetes e envie:

Crie uma página de portfólio em um único arquivo index.html,
com o CSS dentro do próprio arquivo, sem bibliotecas externas
e sem JavaScript. A página deve ficar bonita e funcionar bem
no celular. Escreva em português.

Sobre mim
Nome: [seu nome completo]
Curso: [seu curso]
Faculdade: [onde você estuda ou estudou]
Uma frase sobre mim: [o que você gosta de fazer]

Projeto: [nome do projeto]
Problema: [qual era o problema e para quem]
O que eu fiz: [a solução em uma ou duas frases]
Como: [dados, método e ferramentas]
Resultado: [o que você conseguiu, só números reais]

Coloque no topo o meu nome, o curso e a faculdade. Depois,
o projeto em quatro blocos com os títulos Problema, O que eu
fiz, Como e Resultado. No rodapé, o link do meu GitHub:
https://github.com/[seu-usuario]

Use somente as informações acima: não invente números,
empresas, depoimentos, fotos nem links. Não inclua formulários.
Responda só com o código completo do arquivo.
Tem mais de um projeto? Repita o bloco "Projeto / Problema / O que eu fiz / Como / Resultado" para cada um, antes do parágrafo "Coloque no topo…".

2.3 · Salve o arquivo

  1. Copie todo o código que a IA devolveu (muitas mostram um botão Copiar no canto do código).
  2. Abra o Bloco de Notas, cole e vá em Arquivo → Salvar como.
  3. Em Tipo, escolha Todos os arquivos (*.*). Em Nome, escreva index.html, tudo em minúsculas. Em Codificação, escolha UTF-8. Salve.
  4. Dê dois cliques no arquivo salvo: a página abre no navegador. É assim que ela vai ficar na internet.
Não gostou de algo? Peça à própria IA, na mesma conversa: "deixe as cores mais sóbrias", "aumente a fonte", "troque a ordem dos blocos". Depois, salve o código novo por cima do arquivo antigo.

Passo 3 · Conferir antes de publicar

Abra a página no navegador e leia tudo. Ela só pode ir para o GitHub se todas as respostas forem "sim":

  • Nenhum nome, CPF, RA, telefone ou e-mail de outra pessoa (colegas, professores, pacientes, clientes)?
  • Nenhum dado da empresa do estágio ou do trabalho (clientes, valores, planilhas, prints de sistema interno)?
  • Nenhuma senha, chave de API ou link privado?
  • Se tiver gráfico ou tabela, os dados são públicos, inventados ou anonimizados?
  • Todo número e toda frase sobre você é verdade? A IA às vezes inventa: apague o que você não disse.
Na dúvida, não publique. Depois que a página está no ar, qualquer pessoa pode copiá-la, e o histórico do GitHub guarda até o que você apagar depois.

Passo 4 · Criar o repositório e subir a página

Repositório é a pasta do projeto no GitHub, com o histórico de todas as versões. O do portfólio tem um nome especial, e é esse nome que faz o site aparecer.

  1. No GitHub, no canto superior direito, clique em + → New repository.
  2. Em Repository name, escreva exatamente SEU-USUARIO.github.io, trocando SEU-USUARIO pelo seu nome de usuário. Ex.: mariasilva.github.io.
  3. Em Description, uma frase: "Meu portfólio".
  4. Deixe marcado Public. O site grátis só funciona com repositório público.
  5. Marque Add a README file e clique em Create repository.
  6. Na página do repositório, acima da lista de arquivos, clique em Add file → Upload files.
  7. Arraste só o arquivo index.html para a página (o arquivo, e não a pasta onde ele está).
  8. Embaixo, em Commit changes, escreva na primeira caixa o que você está enviando, por exemplo Primeira versão do portfólio, e clique no botão verde Commit changes.
"Commit" é o registro de uma mudança, com a mensagem que você escreveu. Cada vez que você subir uma versão nova do index.html (repetindo os passos 6 a 8), o GitHub guarda a anterior no histórico.

Passo 5 · Ver o site no ar e entregar

Como o repositório tem o nome SEU-USUARIO.github.io, o GitHub Pages publica o index.html sozinho. Não precisa configurar nada.

  1. Espere de 1 a 5 minutos depois do commit.
  2. Abra https://SEU-USUARIO.github.io no navegador. Se ainda não abrir, espere mais um pouco e recarregue.
  3. Para conferir: no repositório, Settings (engrenagem, no topo) → Pages (menu da esquerda). Quando estiver pronto, aparece "Your site is live at…" com o link.
  4. Abra o link também no celular, para ver se ficou bom.
  5. Entregue ao professor os dois links: o do site (https://SEU-USUARIO.github.io) e o do repositório (https://github.com/SEU-USUARIO/SEU-USUARIO.github.io).
Mudou o arquivo? Suba o index.html novo pelo mesmo caminho (Add file → Upload files): ele substitui o antigo e o site se atualiza sozinho em alguns minutos.

Para depois do exercício

  • Coloque o link do site e do GitHub no LinkedIn, na seção Destaques.
  • Fixe seus melhores repositórios no perfil: Customize your pins.
  • Quando tiver mais projetos, peça à IA para acrescentá-los à mesma página.

Deu erro? Os mais comuns

Clique no problema para ver a solução.

O site abre com "404 There isn't a GitHub Pages site here"

Confira, nesta ordem: o repositório se chama exatamente SEU-USUARIO.github.io, com o seu usuário; o repositório é público; o arquivo se chama exatamente index.html, em minúsculas; e ele está solto no repositório, não dentro de uma pasta. Se tudo estiver certo, espere uns minutos: a primeira publicação pode demorar.

O site mostra o texto do README em vez da minha página

O GitHub não encontrou o index.html. Veja se o arquivo subiu mesmo (ele aparece na lista de arquivos do repositório) e se o nome está certo: Index.html, index.html.txt ou portfolio.html não funcionam.

O arquivo salvou como "index.html.txt"

O Bloco de Notas colocou .txt no fim. Salve de novo escolhendo Tipo: Todos os arquivos (*.*). Para ver a extensão dos arquivos no Windows: no Explorador de Arquivos, Exibir → Mostrar → Extensões de nomes de arquivos.

A página aparece com letras estranhas no lugar dos acentos (Ã©, Ã§)

O arquivo foi salvo sem UTF-8. Salve de novo pelo Bloco de Notas com Codificação: UTF-8. Se continuar, peça à IA para incluir <meta charset="utf-8"> no começo do arquivo.

A página aparece toda sem cor, só texto

A IA provavelmente separou o CSS num segundo arquivo. Peça de novo: "coloque todo o CSS dentro do index.html, numa tag style".

Errei o nome do repositório

O nome precisa ser igual ao seu usuário, letra por letra. Se você errou o usuário, o repositório até é criado, mas o site não aparece. Para renomear: Settings → General → Repository name.

Publiquei uma informação que não devia

Apague a informação do index.html e suba o arquivo de novo. Como o histórico guarda a versão antiga, o mais seguro é apagar o repositório (Settings → General → lá embaixo, Delete this repository) e criá-lo de novo com o arquivo corrigido. Se era uma senha, troque-a na hora.
