# Portfólio de Jader Zerbini

Meus projetos de dados e software, contados como histórias: o problema, o que eu fiz, como e o resultado.
Cada projeto abre um painel com um vídeo curto da tela real do sistema funcionando.

No ar em **https://jaderzerbini.github.io**, publicado pelo GitHub Pages.

## Arquivos

| Arquivo | O que é |
|---|---|
| `index.html` | O portfólio: abertura, as duas listas de projetos e o painel de cada um |
| `projetos.js` | Os textos dos projetos e a legenda de cada vídeo. Para mudar um texto, edite aqui |
| `site.js` | Monta as listas e cuida dos vídeos (miniaturas que tocam sozinhas, painel e fundo) |
| `style.css` | O visual cyberpunk das duas páginas |
| `guia.html` | Guia passo a passo para criar a conta, o primeiro repositório e publicar um projeto |
| `videos/` | Os vídeos de cada projeto (`.webm`), as capas (`.jpg`) e o fundo |
| `fontes-dos-videos/muro.html` | O muro de telas inclinado que vira o vídeo de fundo |

## Os vídeos

São as **telas reais** dos projetos, gravadas no navegador com o Playwright. Cada sistema rodou no meu computador com
dados de exemplo: nenhum dado de cliente, aluno ou empresa aparece. Os projetos que não são páginas web (a urna e o
D&D) aparecem em prints reais animados, e o jogo Dim foi gravado dentro do próprio Godot.

No celular, ou com economia de dados ligada, os vídeos não tocam sozinhos: aparecem as capas.

Site feito à mão, sem framework: HTML, CSS e um pouco de JavaScript.
